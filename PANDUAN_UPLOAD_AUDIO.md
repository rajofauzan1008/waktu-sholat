# 📖 Panduan Aplikasi Waktu Sholat

## 🔊 Upload File Azan MP3 ke GitHub

1. Buat folder `audio/` di root repo
2. Upload `azan.mp3` ke folder tersebut
3. Aktifkan GitHub Pages → Settings → Pages → Source: main
4. URL `rajofauzan1008.github.io/waktu-sholat/audio/azan.mp3` sudah dikonfigurasi ✅

## 🧭 Kompas Kiblat
- **Android**: Sensor aktif otomatis, tidak perlu izin
- **iOS**: Tap tombol "Aktifkan Kompas" yang muncul di layar
- Putar HP hingga ikon 🕋 ada di atas → kamu menghadap kiblat
- Sensor mati otomatis saat pindah tab (hemat baterai)
